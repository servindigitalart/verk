# System 09 — WATERLÜ

## Problem

Restaurants need to be convinced, not just informed, that a sustainable water filtration system is worth adopting — which means the site has to carry a full brand identity and a working lead funnel simultaneously, for a real business, on a real timeline, iterated through several full redesigns before it was right.

## System

WATERLÜ is a B2B marketing website built to acquire restaurants for a sustainable water filtration system. It combines storytelling, brand-driven art direction (Mexican Core aesthetic, film grain, warm lighting), custom scroll animation, and a conversion architecture — landing pages, an impact page, an about page, and lead-capture forms — into one production site, built and iterated for a real client under real business constraints.

## Architecture

- **Presentation** — Astro 4, Tailwind CSS, GSAP (scroll animation, native Intersection Observer)
- **Logic** — Netlify Forms (lead capture)
- **Infrastructure** — Netlify, GitHub, automatic deployment
- **Typography / Brand** — Plus Jakarta Sans (Fontsource), AI-generated photography directed toward a specific brand aesthetic

## Current State

Operativo. Full responsive site live in production: landing pages, impact page, about page, custom animations, conversion forms, and real photography integration — the product of several complete redesigns before arriving at the current identity.

## Capabilities Demonstrated

- Executing for a real business under real commercial constraints, not a self-directed project
- Translating brand strategy into a working, converting interface
- Balancing performance, storytelling, and conversion in the same build
- Iterative, collaborative delivery — including the willingness to fully redesign when the first direction wasn't right
- Production deployment discipline (CI/CD via Netlify + GitHub)

## Technologies

Astro 4, Tailwind CSS, GSAP, Netlify Forms, Netlify, GitHub, Fontsource (Plus Jakarta Sans)
