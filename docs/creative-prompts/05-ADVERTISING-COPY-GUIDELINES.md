# 05 · Reglas de copy publicitario — VERK

> Reglas para el copy de imágenes individuales (modo A) y carruseles (modo B). Los prompts 01 y 02 ya las incluyen en versión condensada; este documento es la referencia completa para redactar o revisar.

## 1. El marco: Problema → Tensión → Sistema → Capacidad → Acción

| Tiempo | Función | Reglas | Ejemplo |
|---|---|---|---|
| **Problema** | El lector se reconoce | Una escena concreta, en presente, con objetos reales. Nunca una abstracción («ineficiencias operativas»). | «Te escribieron. Nadie contestó.» |
| **Tensión** | Por qué importa | La consecuencia lógica, sin cifras ni miedo. Puede ser una pregunta del método. | «Cada mensaje sin respuesta es una conversación que empezó con otro.» |
| **Sistema** | Qué lo resuelve | El cambio de pieza suelta a sistema conectado. Aquí vive el posicionamiento. | «No te falta otra herramienta. Te falta el sistema que las conecte.» |
| **Capacidad** | Qué hace VERK | Mecanismo concreto con las disciplinas reales. Verbos: conectamos, automatizamos, construimos, verificamos. | «Conectamos WhatsApp, formularios y CRM. El seguimiento ocurre solo.» |
| **Acción** | Qué hacer | Un solo CTA. | «Solicitar auditoría» + «Auditoría gratuita y personalizada · Por WhatsApp» |

**En imagen individual:** el titular carga el Problema o la Tensión; el texto secundario, Sistema + Capacidad; el CTA, la Acción. Si la pieza es de posicionamiento (no de conversión), el CTA puede omitirse.

**En carrusel de cinco slides:** un tiempo por slide (1 Problema, 2 Tensión, 3 Sistema, 4 Capacidad, 5 Acción). Si hay más de cinco, la Tensión o la Capacidad se dividen; el slide final siempre es la Acción.

## 2. Situaciones reales (banco de material)

Usa estas escenas; no inventes datos alrededor de ellas.

| Tema | Escenas reconocibles |
|---|---|
| Mensajes sin respuesta | Un WhatsApp de las 11 de la noche · un chat con 80 mensajes sin leer · «¿precio?» sin contestar |
| Cotizaciones pendientes | Una cotización que se iba a mandar «mañana» · la misma cotización armada a mano cada vez |
| Seguimientos olvidados | El «lo pienso y te aviso» que nadie retomó · el seguimiento que dependía de una persona de vacaciones |
| Tareas repetitivas | Confirmar citas una por una · enviar la misma información diez veces al día |
| Herramientas desconectadas | El CRM no sabe lo que pasó en WhatsApp · la agenda no sabe lo que se cotizó |
| Procesos manuales | Pasar datos de WhatsApp a una hoja de cálculo · el mismo cliente tres veces con tres teléfonos |
| Falta de continuidad | El proceso cambia según quién esté disponible |
| Formularios | Solicitudes que llegan a un correo que nadie revisa |
| IA aplicada (como posibilidad, nunca como caso entregado) | Responder preguntas frecuentes con el contexto del negocio · clasificar mensajes entrantes · preparar el borrador de una cotización · resumir una conversación larga |

## 3. Formato y longitud (para que el copy funcione dentro de la imagen)

| Elemento | Longitud | Forma |
|---|---|---|
| **Titular** | 3–9 palabras; 1–3 líneas de ≤ 22 caracteres | Dos tiempos con punto final («X. Y.») o una frase con punto. Caja de oración. |
| **Texto secundario** | 8–24 palabras; máximo 2 frases | Concreto, sin adjetivos vacíos. |
| **Etiqueta mono** | 1–5 palabras | MAYÚSCULAS. Numeración (`01 / 05`), tema o sección. Nunca la marca. |
| **Microcopy** | 2–6 palabras | Canal, condición o anotación técnica («POR WHATSAPP», «AUDITORÍA GRATUITA Y PERSONALIZADA»). |
| **CTA** | «Solicitar auditoría» | Es el único CTA de conversión. «Ver cómo funciona» o «Ver sistemas» solo en piezas de reconocimiento. |

Las preguntas se permiten como titular (el método las usa), pero no más de una pieza de cada tres.

## 4. Fórmulas de titular (variar; no repetir la misma dos veces seguidas)

| Fórmula | Estructura | Ejemplo |
|---|---|---|
| Escena | Momento concreto del problema | «Te escribieron. Nadie contestó.» |
| Contraste | X. No Y. | «Construimos sistemas. No sitios.» |
| Pregunta del método | ¿Dónde / qué…? | «¿Qué tarea se repite más?» |
| Inventario | Tienes X. Tienes Y. Falta Z. | «Tienes las herramientas. Te falta el sistema.» |
| Redefinición | Tu X no es Y. Es Z. | «Tu sitio no es una vitrina. Es la entrada.» |
| Uno y varios | N piezas. Un sistema. | «Cuatro disciplinas. Un sistema.» |
| Mecanismo | Lo que pasa cuando hay sistema | «El seguimiento ocurre. Aunque nadie se acuerde.» |
| Dos actos | Lo visto. La invitación. | «Ya viste cómo pensamos. Ahora construyamos el tuyo.» |

## 5. Claims

**Sí:**
- describir el mecanismo («para que nada dependa de la memoria de alguien»);
- la auditoría gratuita y personalizada;
- el método de cuatro pasos;
- verificar antes de entregar.

**No:**
- cifras, porcentajes, ROI ni tiempos («responde en 5 segundos»);
- «24/7»;
- «nunca pierdas un cliente»;
- testimonios;
- clientes inventados;
- presentar proyectos propios como clientes (solo WATERLÜ es cliente);
- resultados no verificados («duplica tus ventas»);
- plazos;
- urgencia falsa.

## 6. Lenguaje

**Usar:** sistema, conectar, seguimiento, continuidad, operación, flujo, construir, verificar, integrar, recorrido del cliente.

**Evitar:**
- soluciones (innovadoras);
- transformación digital;
- siguiente nivel;
- potenciar;
- impulsar tu crecimiento;
- de vanguardia;
- expertos en;
- 360;
- apasionados;
- casos de éxito;
- contáctanos;
- premium;
- «ecosistema digital» como muletilla.

**Prueba de intercambiabilidad:** si el titular podría firmarlo cualquier agencia, se reescribe.

## 7. Revisión antes de aprobar

- [ ] ¿El problema es una escena reconocible y no una abstracción?
- [ ] ¿Aparece el sistema (no una herramienta aislada)?
- [ ] ¿Hay cifras, garantías o testimonios? → eliminar.
- [ ] ¿El titular cabe en ≤ 3 líneas de ≤ 22 caracteres?
- [ ] ¿Un solo CTA, y es «Solicitar auditoría» si la pieza es de conversión?
- [ ] ¿La marca aparece como «Verk» en el texto, y el logo como el wordmark de la imagen de referencia (nunca escrito como texto en su lugar)?
- [ ] ¿Ortografía y acentos correctos (cotización, auditoría, también, está)?
